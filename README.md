# Monu Kushwaha — Minimalist Portfolio

Personal developer portfolio with a clean, high-contrast **black and white minimalist design**.

🌐 Live Website: **[https://monukushwaha9026.github.io](https://monukushwaha9026.github.io)**

---

## 🧭 Structure & Sections

The site features a sticky **left navigation sidebar** with four main sections:

1. **Profile:**
   - Name, handle (`@Monukushwaha9026`), and direct social links (GitHub, LinkedIn, Email).
   - Concise personal summary and design philosophy.
   - **3 Recent Projects** (GetNow, PeerDrop, LexiconGarden) with live links.
2. **My Projects:**
   - Complete project catalog in a consistent, clean card layout.
   - Live demo links (GitHub Pages / Render) and GitHub source links.
3. **My Skills:**
   - Natural spoken languages (Hindi, English).
   - Programming languages (JavaScript, Python, HTML5, CSS3).
   - Developer tools & platforms (Git, GitHub, GitHub Pages, Render, VS Code, DevTools).
   - Core technical disciplines (WebRTC, REST APIs, CORS, Minimal UI/UX).
4. **My Learning:**
   - Academic education and university/college coursework.
   - Continuous self-directed web engineering milestones.

## 🎨 Theme Details

- **Minimalist Aesthetic:** High-contrast black and white styling inspired by clean modern web design principles.
- **Pure Client-Side:** Ultra-fast, zero-dependency, and hosted directly on **GitHub Pages**.
